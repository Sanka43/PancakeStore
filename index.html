PancakeStore

Downgrade App Store apps without a jailbreak.

A jailed, exploit-less downgrader for iOS 16.4 and later — forked from MuffinStore Jailed.

Download IPA v1.3.1 View on GitHub

What it does

PancakeStore lets you reinstall older versions of apps you already own on the App Store. It runs jailed — no kernel exploits, no TrollStore requirement, no jailbreak.

Features

Built for day-to-day downgrading — share from the App Store, export IPAs, and keep the cache clean.

  • No jailbreak Works on stock iOS 16.4+ via sideloading.
  • No exploits Uses Apple authentication and App Store version delivery.
  • Share Extension Send an App Store link straight into PancakeStore.
  • Export IPA Save the downgraded package after install for archival.
  • iPad-ready UI Proper layout for larger screens, plus a settings page.
  • Localizations Spanish, Arabic, Dutch, Vietnamese, Italian, Swedish, Romanian, Norwegian, and more.
  • Auto-clean caches Download and server caches clear themselves so storage stays tidy.

Requirements

Meet these before you install.

  1. Device running iOS 16.4 or later.
  2. An Apple ID with 2FA — ideally the one signed into the device.
  3. A sideloading method of your choice (TrollStore, LiveContainer, AltStore, Sideloadly, and similar are supported).

Install

Sideload the official IPA, then trust the signing identity if your method requires it.

  1. Download PancakeStore_v1.3.1.ipa from the button above or the GitHub Releases page.
  2. Install with your preferred sideloading tool.
  3. If prompted, trust the developer profile under Settings → General → VPN & Device Management.
  4. Open PancakeStore and sign in with your Apple ID when ready to downgrade.

Prefer the official release assets only. Avoid third-party IPA mirrors.

How to use

The target app must satisfy every rule below.

  • Purchased from the App Store with the same Apple ID you log in with.
  • Not installed on the device (offloading counts as removed).
  • Has valid older versions available to downgrade to — some apps do not.

Do not ask for support if a specific app cannot be downgraded or crashes on launch. That is outside what maintainers can fix.

Troubleshooting

“Failed to get pod”
Usually means this Apple ID cannot complete login, or Apple’s servers changed authentication. Updating to the latest PancakeStore may help; opening issues about login will not speed up a fix.
“Safari can’t open the page”
Go to Settings → Apps → Safari → Privacy & Security, and disable Not Secure Connection Warning. Also check that VPN or custom DNS is not blocking the flow.
Login fails randomly
Apple changes server-side auth often. Stay on the latest release. Auth breakage is expected sometimes and is not something support can rush.

Warnings

Use at your own risk. Downgrading can delete or corrupt app data. There is no guarantee that user data will be retained.

Authentication may break at any time because of Apple’s backend changes. If login fails, update PancakeStore first — do not open issues solely about login failures.
