About

What is PancakeStore?

PancakeStore is a free iOS app downgrader that allows iPhone and iPad users to install older versions of App Store apps without a jailbreak. Designed for iOS 16.4 and later, PancakeStore works in a jailed environment and does not require kernel exploits or TrollStore.

Based on MuffinStore Jailed, PancakeStore provides a cleaner interface, improved performance, and a simple way to restore previous app versions when updates introduce bugs, remove features, or cause compatibility issues.

With PancakeStore, users can easily manage App Store app versions directly on their devices while enjoying a beginner-friendly downgrade experience.

Install

How to Install PancakeStore IPA

Installing PancakeStore is simple.

  1. Download the IPA Download the latest PancakeStore IPA.
  2. Open your sideloading tool Open your preferred sideloading tools.
  3. Import the IPA file Import the IPA file.
  4. Sign the app Sign the app with your Apple ID.
  5. Install PancakeStore Install PancakeStore.
  6. Trust the developer profile Trust the developer profile if required.
  7. Sign in Open PancakeStore and sign in with the same Apple ID used to download the target app.

Prefer the official release assets only. Avoid third-party IPA mirrors.

Usage

How to Downgrade Apps

Using PancakeStore is easy — from sign-in to install in five steps.

  1. Open PancakeStore Launch the app on your iPhone or iPad.
  2. Sign in Use your Apple ID with 2FA enabled.
  3. Find your app Search for an app you've previously downloaded.
  4. Pick a version Choose an available older version from the list.
  5. Install Confirm and install the selected version.

Older versions are only available if Apple still provides them.

Good to know

Important Notes

Keep these in mind before downgrading.

Previously downloaded The app must have been downloaded before using the same Apple ID.
Not currently installed The app should not already be installed on your device.
Availability varies Some apps may not offer older versions at all.
Apple can change things Authentication may occasionally stop working due to changes on Apple's servers.

Quick fixes for the most common issues.

Update PancakeStore to the latest version and try again.

FAQ

PancakeStore FAQ

Answers to the questions people ask most.

What is PancakeStore iOS?

PancakeStore iOS is an app downgrader that lets you install older versions of App Store apps on iPhone and iPad without jailbreak or exploits.

Does PancakeStore require jailbreak?

No. PancakeStore app works on stock iOS and does not require jailbreak, TrollStore, or kernel exploits.

Which iOS versions support PancakeStore?

PancakeStore supports iOS 16.4 and later on compatible iPhone and iPad devices.

Can I download PancakeStore APK on iPhone?

No. PancakeStore APK is an Android format. iOS users should install the PancakeStore IPA version instead.

How does PancakeStore downgrade apps?

PancakeStore installs older App Store versions available from Apple servers. The app must be previously downloaded with the same Apple ID.

Can I install PancakeStore with SideStore or Scarlet?

Yes. You can install PancakeStore using sideloading tools like SideStore, Scarlet, AltStore, or similar IPA installers.

Is PancakeStore related to WaffleStore?

PancakeStore is based on the same idea as MuffinStore Jailed. It is not the same as WaffleStore, but both focus on App Store app management.

Can PancakeStore install Minecraft iOS older versions?

Yes, if an older Minecraft iOS version is still available on Apple's servers and linked to your Apple ID, PancakeStore may allow installation.

Does PancakeStore need TrollStore?

No. PancakeStore works without TrollStore and can be installed through normal sideloading methods.

Why does PancakeStore login fail?

Apple authentication can change at any time. Update PancakeStore to the latest version and make sure you use the correct Apple ID with 2FA enabled.
